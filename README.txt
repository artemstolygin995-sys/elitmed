ELITMED — РЕДИЗАЙН, ВЕРСИЯ 1

Запуск в Visual Studio Code:
1. Распакуйте архив.
2. Откройте папку в Visual Studio Code.
3. Откройте index.html через расширение Live Server.

Основные файлы:
- index.html — структура сайта;
- styles.css — оформление и адаптивность;
- script.js — анимации, фильтры, галереи и формы;
- data/content.js — данные услуг, врачей и каталогов;
- assets/images — изображения исходного сайта.

Регистрация и вход в этой локальной версии сохраняются в браузере на устройстве.
Для реальных аккаунтов, работающих на разных устройствах, потребуется подключение
серверной базы данных после выбора хостинга.
